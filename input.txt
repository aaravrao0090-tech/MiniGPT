MiniGPT is a tiny language model experiment.
A language model learns patterns in text and predicts what might come next.
The small model reads examples, learns from them, and generates new text one character at a time.
Learning takes practice. Good experiments change one setting at a time and compare the results.
A transformer uses attention to decide which earlier tokens are useful for predicting the next token.
This project is for learning how neural language models work. Its tiny sample data cannot teach broad knowledge.
